SIRF Atlas7 Inter-Processor Communication (IPC) Device Binding
------------------------------------------------

1) Main node
	Required properties :

	- compatible : shall contain only one of the following:
			"sirf,atlas7-ipc"

	- ranges : the ipc io address range

2) Child nodes
	The main node has serval child nodes which describes
	hardware spinlock and remoteproc devices.

	For the hwspinlock properties please refer to:
	Documentation/devicetree/bindings/hwspinlock/sirf,hwspinlock.txt

	For the remoteproc properties please refer to:
	Documentation/devicetree/bindings/remoteproc/sirf,remoteproc.txt

Example:
	ipc@13240000 {
		compatible = "sirf,atlas7-ipc";
		ranges = <0x13240000 0x13240000 0x00010000>;
		#address-cells = <1>;
		#size-cells = <1>;

		hwspinlock {
			num-spinlocks = <30>;
		}

		remoteproc {
			sirf,ipc-mem = <0x40000000 0xD0000000 0x200000>;
		}
	};
