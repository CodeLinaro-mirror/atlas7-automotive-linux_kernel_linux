*SiRFatlasVI UART Controller
Required property:
reg: Offset and length of the register set for the device
interrupts: Uart interrupt number
fifosize: Uart hardware rx/tx fifo size
clocks: Uart clock frequency
sirf,uart-dma-rx-channel: Uart rx dma channel number
sirf,uart-dma-tx-channel: Uart tx dma channel number

example:
uart0: uart@b0050000 {
			cell-index = <0>;
			compatible = "sirf,prima2-uart";
			reg = <0xb0050000 0x1000>;
			interrupts = <17>;
			fifosize = <128>;
			clocks = <&clks 13>;
			sirf,uart-dma-rx-channel = <21>;
			sirf,uart-dma-tx-channel = <2>;
};
