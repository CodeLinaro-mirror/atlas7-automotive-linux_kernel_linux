* CSR SiRFprimaII Serial Peripheral Interface

Required properties:
- compatible : Should be "sirf,prima2-spi" or "sirf,marco-spi" or
		"sirf,prima2-usp-spi" or "sirf,marco-usp-spi"
- reg : Offset and length of the register set for the device
- interrupts : Should contain SPI interrupt
- sirf,spi-num-chipselects : Contains the number of the chipselect
- cs-gpios : Specifies the gpio pins to be used for chipselects.
if want use spidev driver, you may add sub node in spi, add compatible
property "spidev" in the subnode

Example:

spi0: spi@b00d0000 {
	compatible = "sirf,prima2-spi";
	reg = <0xb00d0000 0x10000>;
	interrupts = <15>;
	sirf,spi-num-chipselects = <2>;
	cs-gpios = <&gpio 18 0>,
		   <&gpio 19 0>;
	spidev {
		compatible = "spidev";
		reg = <0>;
		spi-max-frequency = <1000000>;
	};
};
